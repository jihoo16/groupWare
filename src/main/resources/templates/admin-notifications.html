시스템 설정 템플릿 관리 발송 이력

알림 시스템 가동 상태 사고·점검 시 모든 직원에게 가는 알림을 한 번에 차단하는 비상 스위치

알림 발송 가동 중
이 스위치를 끄면 시스템 전체에서 사내 모든 직원에게 가는 알림이 즉시 멈춥니다. 예를 들어 잘못된 결재 알림이 대량 발송되거나 야간 점검으로 알림이 가서는 안 되는 상황 같은 비상 시에만 OFF로 두세요. 평상시에는 항상 ON 입니다.
발송 일시정지
위쪽 비상 스위치와 달리, 일시정지는 Mattermost 서버가 다운되었을 때 짧은 시간만 발송 시도를 멈춰두는 기능입니다. 그 사이 발생한 알림은 사라지지 않고 대기 상태로 쌓이며, 정해진 시각이 되면 자동으로 다시 발송됩니다. Mattermost 가 안 되는 게 확인되면 즉시 정지해서 의미 없는 재시도를 막으세요.

봇 접속 정보 MM 담당자가 발급한 봇 계정 정보. 토큰은 AES-GCM 암호화 저장됨

Mattermost 서버가 발급한 봇 계정의 내부 ID. 직접 입력하지 않고 [봇 연결 테스트] 버튼으로 자동 조회됩니다.
※ 비밀키는 마스킹되어 표시됩니다. 변경할 때만 새 값을 입력하세요. 데이터베이스에는 암호화되어 저장되며 평문으로 보관되지 않습니다.
시스템 공지를 보낼 Mattermost 채널 이름. 비워두면 채널 공지 발송 기능이 꺼집니다.

재시도 · 만료 정책 발송이 실패했을 때 어떻게 처리할지 정합니다.

이 횟수까지 시도해도 실패하면 자동 재시도를 멈추고 요청자에게 안내 알림을 보냅니다. 요청자는 본인 메시지의 [다시 보내기] 버튼으로 직접 재시도할 수 있습니다.
이후 재시도마다 대기시간이 2배씩 늘어납니다 (예: 60초 → 2분 → 4분 → 8분 → 16분).
알림이 발생한 뒤 이 시간이 지나도록 발송이 안 되면 만료 처리됩니다. 기본 1440분(24시간). "회의 5분 전" 같은 시의성 있는 알림이 하루 뒤에 도착하는 일을 막기 위한 안전장치입니다.

발송 경로 검증 지금 본인 Mattermost 인박스로 테스트 메시지 1통을 보냅니다

본인 사번으로 MM 사용자를 조회하고, 봇과의 DM 채널을 만들고, 실제 메시지를 발송하는 전체 경로를 한 번에 검증합니다. 성공하면 본인 Mattermost 인박스에 봇 메시지가 한 통 도착합니다. 다른 직원에게는 가지 않습니다.

시스템 공지 발송 공지용 Mattermost 채널로 공지 메시지를 보냅니다

위 [봇 접속 정보] 의 공지용 채널 ID 로 메시지가 발송됩니다. 그 채널에 봇이 멤버로 추가되어 있어야 발송이 성공합니다. 인박스 동시 발송 을 켜면 모든 활성 직원의 그룹웨어 인박스에도 같은 공지가 들어갑니다.
